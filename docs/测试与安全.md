## 自动化检查
后端 `mvn -B -f backend/pom.xml spotless:check test package`，包含纯依赖图规则和MockMvc完整HTTP流程。前端 `npm ci`、`npm run format:check`、`npm run lint`、`npm test`、`npm run build`，覆盖CSRF/过期会话/错误反馈及按钮与依赖、独立核验、期限、补偿的状态规则。
`docker compose config --quiet` 后构建全部镜像。Docker Maven构建运行相同测试，没有跳过测试。H2用于自动化测试，不替代MySQL行为验证。
## 全新MySQL验收
在独立可销毁卷启动MySQL8.4、后端和前端，健康后使用私有ADMIN_PASSWORD登录。`python3 scripts/smoke.py --base http://127.0.0.1:8118 --env .env --allow-test-writes` 创建带TEST标记的虚构人员和方案，检查初始迁移、任务依赖、正式切换前演练门禁、正向完整流程、失败阻断、逆序回退、独立核验、跨部门/本人隔离、修订和重复提交。
脚本生成忽略的.smoke-state.json供本机验收，包含虚构账号及临时测试密码，不可上传。重启本项目后端后使用 `--verify-persistence` 检查业务与证据仍在；必须重新登录。页面验收使用同一独立测试环境、实际业务端/管理端并拍摄当前页面。
## 发布检查
`python3 scripts/release-check.py` 扫描待发布源码、私有凭证、文件头、许可与README图片；校对两个原始微信二维码和原LOGO哈希；`git diff --check` 并逐项检查暂存差异。二维码及LICENSE使用原始文件，不重新生成。
没有声称通过负载测试、专业渗透测试、生产主机切换、客观备份恢复验证或云服务集成。手机窄屏须实际检查后才能声称已验收。
## 安全边界
密码BCrypt12轮；Cookie HttpOnly/SameSite Strict、30分钟会话；匿名仅健康、CSRF引导和登录。连续8次失败限制账号/IP五分钟，单实例内存限流不适合横向扩展。禁用账号、改密码和权限撤销实时复核，密码/散列不返回，不记录认证载荷。SQL值绑定，固定排序，不接收客户端JPQL。
当前版只保存文本，无文件上传/下载路径；JSON报告不拼文件系统路径。角色ALL管理员接口隔离，保护最后可用全范围管理员；外键保护引用人员和历史。不包含SaaS租户隔离、电子签名、不可篡改存证或主动安全监控。
公开部署需HTTPS、Secure Cookie、可信数据库证书验证、独立权限、备份及受控网络。安全问题通过 https://www.zhuatech.cn/ 或微信zhuatech/zhuatech2私下反馈，勿将凭证/真实系统/客户资料写入Issue。
