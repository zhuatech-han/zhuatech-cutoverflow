# CutoverFlow 架构、数据库与接口

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2

## 模型
V1__identity.sql：department、access_role、permission、role_permission、account、nav_menu、dictionary_entry、system_setting、audit_event。
V2__cutover.sql：cutover_plan基线及修订；cutover_step任务；step_dependency有向前置边；cutover_run每次运行及期限；run_task执行/核验/回退独立字段；command_record精确命令重试；flow_event追加事件。外键保护人员、方案及历史引用。索引覆盖部门状态、方案、运行与事件。
初始五类角色、九项权限和十一项菜单，仅管理资料，不伪造运行。READY方案和任务冻结，因此不同运行引用同一基线，不需要复制后可变的任务。方案提交后不能删除，运行没有删除接口。指派账号显示名可能由后台更新，原事件actorId保留身份；当前版本不保存历史姓名快照。
## 事务与范围
写操作锁总部部门行，读已提交隔离下重读当前账号/角色；状态、基线/运行修订、具体指派、职责分离、依赖和期限在同一事务核对。幂等UUID绑定账号、路由/对象、结构化JSON输入的SHA256，不用含分隔符的字符串拼接代替序列化。业务事件与审计同事务提交。成功重试返回当前资料，不重复执行。
ALL读取全部部门，DEPARTMENT本部门，SELF读取关联方案的完整基线及运行。执行仍严格指定具体任务owner/reviewer，指挥动作指定director。SELF不得成为编制或指挥候选。权限更改即时生效，不允许管理员跨过独立指派。
100任务/方案、200运行/方案；1000方案统计上限；10000目录上限；最近500事件展示。读取会访问完整关联基线，不能当成多人外部租户门户。全局写锁适合学习版小规模单实例，不能声称分布式高吞吐。
## 接口
所有 `/api` 业务需登录，写接口需CSRF请求头。先GET /api/auth/csrf获取header/token，再POST /api/auth/login；GET /api/auth/me返回无凭证资料，POST /api/auth/logout注销，POST /api/auth/password验证旧密码改密码并撤销会话。

| 路径 | 功能 |
| --- | --- |
| GET /api/options、/workbench、/dashboard、/audit | 选择资料、本人待办、范围统计、部门审计 |
| GET /api/plans?search=&status=&page=0&size=20&sort=newest | 数据库搜索、状态、分页，size≤100；排序newest/oldest/code |
| POST /api/plans；GET/PUT/DELETE /api/plans/{id} | 创建、完整查询、编辑、删除无提交历史本人草稿 |
| POST /api/plans/{id}/commands/{action} | submit/approve/return/retire |
| POST /api/plans/{id}/steps；PUT/DELETE .../steps/{step} | 任务与依赖维护，仅草稿作者 |
| POST /api/plans/{id}/runs；GET /api/runs/{id} | 指挥人启动运行及读取执行台 |
| POST /api/runs/{id}/tasks/{task}/commands/{action} | start/complete/pass/reject/fail/rollback/rollback-pass/rollback-reject |
| POST /api/runs/{id}/commands/{action} | accept/abort/finish-rollback，仅指挥人 |
| GET /api/runs/{id}/report.json | 同范围业务JSON下载 |
| GET/POST /api/admin/{type}；PUT/DELETE /api/admin/{type}/{id} | 全范围管理员目录 |

命令输入 `version,requestKey,note`；证据至少10字、最多2000字。编辑/新增任务携带方案version；所有任务操作携带运行version。DELETE草稿/任务通过version查询参数。运行输入 `version,requestKey,mode(REHEARSAL或LIVE),reference,deadline(UTC时间)`。账户/角色/菜单等使用有限DTO，不能指定任意实体类或写入密码散列。权限、菜单与系统参数只编辑登记项。
错误码包括UNAUTHENTICATED(401)、FORBIDDEN/OUT_OF_SCOPE/NOT_ASSIGNED(403)、STALE_VERSION/INVALID_STATE/DEPENDENCY_BLOCKED/ROLLBACK_ORDER/REHEARSAL_REQUIRED(409)，统一返回code，不返回凭证或内部栈。
